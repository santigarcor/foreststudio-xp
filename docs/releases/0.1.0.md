First public release of **ForestStudio XP**: better forests for X-Plane 12, built tile by tile from
real satellite and map data, as a desktop app (pick tiles on a map, press Build, fly).

## Download

| System | File |
|---|---|
| Windows 10/11 (64-bit) | `ForestStudio-XP-0.1.0-windows-x64-setup.exe` |
| macOS (Apple Silicon) | `ForestStudio-XP-0.1.0-macos-arm64.dmg` |
| macOS (Intel) | `ForestStudio-XP-0.1.0-macos-x86_64.dmg` (if listed below) |
| Linux (x86-64) | `ForestStudio-XP-0.1.0-linux-x86_64.tar.gz` |

No Python needed: each download includes everything. `SHA256SUMS.txt` lists the checksums.
See the [README](https://github.com/santigarcor/foreststudio-xp#install) for install steps. The
macOS and Linux builds haven't been tested much yet, and the macOS app is unsigned (the README
explains how to open it the first time).

## What's in it

- **Forests where they really are**: ESA WorldCover 10 m land cover and Hansen tree cover, minus
  recent forest loss, cut clear of roads, buildings, water, runways, car parks and building sites
  from OpenStreetMap.
- **Colombia** with hand-tuned forest types: rainforest, Andean montane forest, dry forest, savanna,
  mangroves, páramo, all evergreen, plus oil palm, coconut, banana, coffee, rubber, pine and
  eucalyptus plantations.
- **Any other country or state** from Geofabrik's list (Data → Regions): default forest types that
  pick X-Plane's own forest for the leaf type seen by satellite and the local climate (incl. swamp
  and cloud forest, savanna trees, wetland bushes, orchards). Border tiles read every country file
  that covers them.
- **Town trees and scrub**, kept off buildings, roads, airport grounds and the 300 m past each runway end.
- **FPS-aware settings**: a tree budget per tile, low / medium / high profiles, every setting in
  plain language with its frame-rate cost.
- **One pack for every region**, linked into X-Plane as a single folder link; ForestStudio never
  changes your installed scenery. Several tiles build at the same time, and the map updates as each
  tile finishes.
