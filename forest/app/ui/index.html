Forest types

Forest type = biome (where it is) × elevation band × dense or sparse (tree density). Only evergreen X-Plane forests are offered (no winter look in the Andes).

FPS cost of each type = trees per km² × triangles per tree: ⚡⚡ heavy ≥ 7 M triangles/km² · ⚡ medium 3–7 M · light < 3 M. Lists are sorted lightest first. When a tile hits its Max trees, the trees per km² no longer matter (the cap thins them) but triangles per tree still do.

Plantations

Areas mapped in OpenStreetMap as orchards, plantations or crops. The first rule whose tags match wins (use ↑ to reorder). Inside them the biome's forest is replaced, and trees are planted even where the satellite map sees none.

Biomes

Each biome is a group of ecoregions (RESOLVE Ecoregions 2017) with its own forest types by elevation. Pick a biome to edit it.

Satellite maps

Land cover (ESA WorldCover 2021, 10 m) and tree cover / forest loss (Hansen Global Forest Change 2000–2024, 30 m), downloaded per tile. These are fixed releases, so there's nothing to update.

About

ForestStudio XP builds X-Plane 12 forest scenery from free satellite and map data. Open source (GPL-3.0): github.com/santigarcor/foreststudio-xp. Every built pack includes a CREDITS.txt with the notices below, which the data licenses require.

Delete tiles

Deleted tiles disappear from X-Plane too (the pack is a link to ForestStudio's data folder) and show X-World / default forests again after restarting X-Plane. Downloaded data is fetched again automatically if you rebuild. This can't be undone.
